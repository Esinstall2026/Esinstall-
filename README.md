# ES INSTALL — v0.1

Starter application for the ES INSTALL operations platform.

## Included in this package

- React + TypeScript + Vite foundation
- Responsive dark premium UI
- ES INSTALL visual identity (gold accents)
- Dashboard
- Jobs list and search
- Job Folder
- Operational timeline
- Teams / Builders / Communities module foundations
- Installations / Warranty / Reports / Settings foundations
- Local mock data for the first functional flow

## Run locally

Requirements:
- Node.js 18+ recommended

Commands:

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

For a production build:

```bash
npm run build
```
